PracticalBayesPlot.PracticalBayesPlot — Module
PracticalBayesPlot

Lightweight plotting for the Bayesian workflow: trace plots, posterior densities and intervals, and posterior predictive checks, plus the Makie-style primitives they are built from. Draws figures as SVG, has no dependencies, and loads in milliseconds.

The package exports nothing. The API follows Makie's names (Figure, Axis, lines!, hist!, ...), so load it qualified to use it alongside Makie:

import PracticalBayesPlot as PBP
PBP.traceplot((; mu = randn(1000, 4), sigma = exp.(randn(1000, 4))))

PracticalBayesPlot.traceplot — Function
traceplot(draws; variables=nothing, density=true, figure=(;)) -> Figure

Trace plots: one row per parameter, with each chain's draws against iteration on the left and, when density = true, each chain's density on the right. draws is anything todraws reads, such as a chain or a NamedTuple of iterations × chains matrices. variables picks parameters by name, in order. figure passes keywords to Figure.

PracticalBayesPlot.intervals — Function
intervals(draws; variables=nothing, prob=0.5, prob_outer=0.9, point=median,
          color=:steelblue, figure=(;), axis=(;)) -> Figure
intervals!(ax, draws; ...)

Posterior intervals, one row per parameter from the top down, as bayesplot's mcmc_intervals: a thick line over the central prob interval, a thin line over the central prob_outer interval and a marker at the point estimate, a function of the draws such as median (the default) or mean. The chains are pooled. draws is anything todraws reads.

PracticalBayesPlot.ppcheck — Function
ppcheck(y, yrep; type=:dens_overlay, stat=mean, figure=(;), axis=(;)) -> Figure
ppcheck!(ax, y, yrep; type=:dens_overlay, stat=mean)

Posterior predictive check of the observed data y (a vector) against replicated data sets yrep, one per row (draws × observations), as bayesplot's ppc_* plots. type is

  • :dens_overlay: the density of y over the density of each row of yrep;
  • :ecdf_overlay: the same with empirical CDFs;
  • :hist: histograms of y and of all of yrep pooled;
  • :stat: a histogram of the statistic stat of each row of yrep, with stat(y) marked;
  • :bars: for discrete data, bars counting each value in y, with the median and 90% interval of the counts in yrep.

The overlays draw a line per row, so pass a subset of the draws (say 50) for them, and all of them for :stat.

PracticalBayesPlot.todraws — Function
todraws(x) -> Vector{Pair{String,Matrix{Float64}}}

The posterior draws in x as name => draws pairs, where draws is an iterations × chains matrix. traceplot, densities and intervals read their input with it, so a method for a new type makes all of them accept that type.

x can be

  • a vector: one parameter, one chain;
  • a matrix: iterations × parameters, one chain;
  • a 3-d array: iterations × parameters × chains (MCMCChains' layout);
  • a NamedTuple, an AbstractDict or a vector of pairs name => draws, where each draws is a vector (one chain) or an iterations × chains matrix;
  • with the package loaded, a FlexiChains.FlexiChain, an MCMCChains.Chains, or any Tables.jl table, such as a DataFrame.

In a table, or a NamedTuple or dictionary of vectors, each numeric column is a parameter. A chain (or .chain) column splits the draws into chains; iteration, iter, draw, .iteration and .draw columns are ignored.

Parameters without names are called θ[1], θ[2], ....

PracticalBayesPlot.Axis — Type
Axis(fig[i, j]; title="", xlabel="", ylabel="", xticks=nothing, yticks=nothing,
     limits=nothing, xgridvisible=true, ygridvisible=true)

A 2-d axis placed in cell (i, j) of a Figure; i and j may be ranges to span cells. Attributes can be changed afterwards, e.g. ax.ylabel = "density".

  • xticks, yticks: nothing (automatic), a vector of positions, or a tuple (positions, labels).
  • limits: (xlow, xhigh, ylow, yhigh) or ((xlow, xhigh), (ylow, yhigh)); any entry may be nothing to keep it automatic. See also xlims!.

Plotting into an axis

PracticalBayesPlot.lines! — Function
lines!(ax, x, y; color, alpha=1, linewidth=1.5, linestyle=:solid, label="")
lines!(ax, y)

Connect the points (x[i], y[i]) with straight lines. NaNs break the line. linestyle is :solid, :dash, :dot or :dashdot.

Colours: a name (:steelblue, "red"), a hex string, an (r, g, b) tuple, an integer index into wong_colors, or (colour, alpha). Without color, each plot takes the next colour of the axis's cycle.

source
PracticalBayesPlot.stairs! — Function
stairs!(ax, x, y; step=:pre, kwargs...)

A step function through the points. step = :pre puts each horizontal segment before (left of) its point, :post after it, :center centred on it. Other keywords as lines!.

PracticalBayesPlot.hist! — Function
hist!(ax, data; bins=15, normalization=:none, color, alpha=1,
      strokecolor=:black, strokewidth=0, label="")

Histogram of the finite values in data. bins is a number of equal-width bins or a vector of edges. normalization: :none (counts), :pdf (area 1), :probability (heights sum to 1) or :density (counts / bin width). For outline-only bars, pass color = :transparent and a strokewidth.
