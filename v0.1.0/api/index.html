API

PracticalBayesPlot.PracticalBayesPlot — Module
PracticalBayesPlot

Lightweight plotting for the Bayesian workflow: posterior predictive checks, effect plots, traces, residuals and intervals. Draws figures as SVG, has no dependencies, and loads in milliseconds.

The package exports nothing. The API follows Makie's names (Figure, Axis, lines!, hist!, ...), so load it qualified to use it alongside Makie:

import PracticalBayesPlot as PBP
fig = PBP.Figure()
ax = PBP.Axis(fig[1, 1])
PBP.lines!(ax, 1:10, rand(10))

Figures and axes

PracticalBayesPlot.Figure — Type
Figure(; size=(600, 450), fontsize=12, title="", backgroundcolor=:white)

A figure of size pixels (width, height). Place axes in it with Axis(fig[row, col]). Display it in VS Code, Jupyter or Pluto, open it in a browser with preview, or write it with save.

source
PracticalBayesPlot.Axis — Type
Axis(fig[i, j]; title="", xlabel="", ylabel="", xticks=nothing, yticks=nothing,
     limits=nothing, xgridvisible=true, ygridvisible=true)

A 2-d axis placed in cell (i, j) of a Figure; i and j may be ranges to span cells. Attributes can be changed afterwards, e.g. ax.ylabel = "density".

  • xticks, yticks: nothing (automatic), a vector of positions, or a tuple (positions, labels).
  • limits: (xlow, xhigh, ylow, yhigh) or ((xlow, xhigh), (ylow, yhigh)); any entry may be nothing to keep it automatic. See also xlims!.

PracticalBayesPlot.axislegend — Function

Draw a legend inside ax listing every plot given a label. position is two letters, horizontal then vertical: :lt (left top), :rt, :rb, :lb, :ct, :cb, :lc, :rc or :cc.

Plotting into an axis

PracticalBayesPlot.lines! — Function
lines!(ax, x, y; color, alpha=1, linewidth=1.5, linestyle=:solid, label="")
lines!(ax, y)

Connect the points (x[i], y[i]) with straight lines. NaNs break the line. linestyle is :solid, :dash, :dot or :dashdot.

Colours: a name (:steelblue, "red"), a hex string, an (r, g, b) tuple, an integer index into wong_colors, or (colour, alpha). Without color, each plot takes the next colour of the axis's cycle.

source
PracticalBayesPlot.stairs! — Function
stairs!(ax, x, y; step=:pre, kwargs...)

A step function through the points. step = :pre puts each horizontal segment before (left of) its point, :post after it, :center centred on it. Other keywords as lines!.

source
PracticalBayesPlot.scatter! — Function
scatter!(ax, x, y; color, alpha=1, markersize=8, marker=:circle,
         strokecolor=:black, strokewidth=0, label="")

Markers at the points. markersize is the diameter in pixels; marker is :circle, :rect, :diamond, :utriangle or :dtriangle. x and y may hold strings, which become categories.

source
PracticalBayesPlot.band! — Function
band!(ax, x, lower, upper; color, alpha=1, label="")

Fill the region between lower and upper along x, e.g. a credible band. Without color, the axis's next cycle colour at 30% opacity is used.

source
PracticalBayesPlot.barplot! — Function
barplot!(ax, x, heights; width=nothing, gap=0.2, fillto=0, color, alpha=1,
         strokecolor=:black, strokewidth=0, label="")

Vertical bars of heights centred on x. x may hold strings, which become categories at 1, 2, ... with their names as tick labels. Without width, bars are 1 - gap of the smallest spacing between x values.

source
PracticalBayesPlot.hist! — Function
hist!(ax, data; bins=15, normalization=:none, color, alpha=1,
      strokecolor=:black, strokewidth=0, label="")

Histogram of the finite values in data. bins is a number of equal-width bins or a vector of edges. normalization: :none (counts), :pdf (area 1), :probability (heights sum to 1) or :density (counts / bin width). For outline-only bars, pass color = :transparent and a strokewidth.

source
PracticalBayesPlot.density! — Function
density!(ax, data; npoints=200, bandwidth=nothing, kwargs...)

Gaussian kernel density estimate of data, drawn as a line over the range of the data extended by three bandwidths. bandwidth defaults to Silverman's rule. Other keywords as lines!.

source
PracticalBayesPlot.ecdfplot! — Function
ecdfplot!(ax, data; kwargs...)

Empirical cumulative distribution function of the finite values in data, as a step line. Keywords as lines!.

PracticalBayesPlot.rangebars! — Function
rangebars!(ax, pos, low, high; direction=:y, color=:black, alpha=1,
           linewidth=1.5, whiskerwidth=0, label="")

Line segments from low to high at each position, e.g. credible intervals. direction = :y draws vertical bars at x = pos; :x draws horizontal bars at y = pos. Positions may be strings (categories). whiskerwidth is the width of the end caps in pixels.

Horizontal reference lines across the whole axis. They do not affect the automatic x limits. See also vlines!.
